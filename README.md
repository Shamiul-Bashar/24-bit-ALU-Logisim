# 24-bit ALU using Logisim Evolution

A 24-bit Arithmetic Logic Unit (ALU) designed using **Logisim Evolution** as part of a **Digital Logic Design** project. The ALU performs a variety of arithmetic and logical operations based on control inputs.

---

## 📖 Overview

This project demonstrates the design and implementation of a **24-bit Arithmetic Logic Unit (ALU)** capable of executing multiple arithmetic and logical operations. The circuit is built entirely in **Logisim Evolution** and follows digital logic design principles.

---

## ✨ Features

- 24-bit data processing
- Addition
- Subtraction
- AND
- OR
- XOR
- XNOR
- NAND
- NOR
- NOT
- Shift Left
- Shift Right
- Comparator
- Zero Flag
- Carry Flag
- Overflow Flag

## 🚀 How to Run

1. Install **Logisim Evolution**.
2. Open the `24_bit_ALU.circ` file.
3. Apply input values to Operand A and Operand B.
4. Select the desired operation using the control lines.
5. Observe the output and status flags.
